# Code of Conduct

We want this project to be a respectful, harassment-free space for everyone.

## Expected behaviour

- Be kind and constructive; assume good faith.
- Respect different experiences, languages and skill levels.
- Give and accept feedback gracefully; focus on the work, not the person.

## Unacceptable behaviour

- Harassment, insults, threats, or discriminatory language or imagery.
- Personal or political attacks, trolling, or sustained disruption.
- Publishing others' private information without permission.
- Anything else that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove, edit or reject comments, commits, issues and other contributions that violate this code, and may temporarily or permanently ban contributors for behaviour they deem inappropriate.

To report a problem, use GitHub's private channel: open a [private security advisory](https://github.com/fab-agent/community/security/advisories/new) marked "conduct", or use GitHub's "Report content" feature on the item. Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
